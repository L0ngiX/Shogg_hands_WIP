## Manual installation 💜

*Download* the archive and transfer ****only**** the ***Shoggoth-hands*** (**in Shogg hands sprites**) to folder on the path: 

[**Steam's game root folder**]:\SteamLibrary\steamapps\common\White Knuckle\White Knuckle_Data\Mods\Cosmetics\Hands\ [Insert the **Shoggoth-hands** folder]
